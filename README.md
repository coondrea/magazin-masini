# Magazin Masini

Magazin online de vanzare a masinilor noi si second-hand, realizat cu Django (proiect pentru materia Django, in curs de dezvoltare).

## Documentatie

[Documentatia proiectului (Google Docs)](https://docs.google.com/document/d/19TDaCG_4Ka9z9h9N74kIIuUX3kSSVCBdDWI3N5n0g7A/edit?tab=t.0)

## Rulare locala

```bash
pip install django
python manage.py migrate
python manage.py runserver
```
